# med-nfc

NFC 태그를 약 상자에 붙이면 폰으로 복약 안내 음성을 들려주는 프로젝트.
자세한 계획은 `NFC-음성안내-실행계획-최종.md` 참조.

## drugs.json 작성 규칙

약 데이터베이스는 `drugs.json` 한 파일로 관리한다. 아래 형식을 반드시 지킬 것.

### 파일 구조

```json
{
  "version": "2026-08-04",
  "drugs": [
    {
      "code": "med01",
      "name": "타이레놀정500밀리그람",
      "shortName": "해열진통제",
      "script": "읽어줄 문장",
      "displayText": "화면에 보일 짧은 텍스트"
    }
  ]
}
```

### 필드 설명

| 필드 | 설명 |
|---|---|
| `code` | 약 번호. `med01`, `med02`... 순서로, 반드시 따옴표 붙여서 문자열로 |
| `name` | 약 정식 이름 |
| `shortName` | 짧은 이름 (목록에 표시됨) |
| `script` | 폰이 읽어줄 문장 |
| `displayText` | 화면에 보일 짧은 텍스트 |

### 규칙

1. 파일 이름은 정확히 `drugs.json`, 저장소 루트에 위치
2. 배열 이름은 반드시 `drugs` (다른 이름 쓰지 말 것)
3. 필드 이름 철자 그대로 유지: `code`, `name`, `shortName`, `script`, `displayText`
4. `code` 번호는 한 번 정하면 이후 바꾸지 않는다 (NFC 태그와 이미 약속된 번호라서)
